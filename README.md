# ศักยภาพพื้นที่ภูเก็ต (Phuket Potential Map)

เว็บวิเคราะห์ศักยภาพพื้นที่รายตำบลของจังหวัดภูเก็ต สำหรับโครงการ THEOS-2 / GISTDA
ด้านการจัดการเมืองและเส้นทางระเบียงเศรษฐกิจ

เขียนด้วย **React + TypeScript + Vite** แผนที่ใช้ **MapLibre** กับแผนที่พื้นหลังจาก **GISTDA Sphere**
ไม่ต้องใช้ database ข้อมูลทั้งหมดเป็นไฟล์ใน `public/data/`

## หน้าในเว็บ
| หน้า | ทำอะไร |
|---|---|
| หน้าแรก | อธิบายโครงการ ตัวเลขสรุป และ 5 อันดับแรก |
| แผนที่วิเคราะห์ | แผนที่ 17 ตำบล ปรับหลักเกณฑ์ (น้ำหนักปัจจัย) ได้ เปิด/ปิดชั้นข้อมูล คลิกตำบลเพื่อดูรายละเอียด |
| จัดอันดับ | ตารางเรียงได้ ค้นหาได้ ดาวน์โหลด CSV/JSON |
| ภารกิจ | สื่อการเรียนรู้ 6 ขั้น: บทบาท → หลักฐาน → หลักเกณฑ์ → ตัดสินใจ → Stress Test → สรุป |
| วิสัยทัศน์ | ใครใช้ได้อย่างไร การต่อยอดด้วยข้อมูล GISTDA และการใช้กับเรื่องอื่น |
| วิธีคิดและแหล่งข้อมูล | สูตร แหล่งข้อมูล วันที่ และข้อจำกัด |

## วิธีรันในเครื่องตัวเอง
1. ติดตั้ง Node.js เวอร์ชัน 22 ขึ้นไป จาก https://nodejs.org
2. เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์
   ```
   npm ci
   npm run dev
   ```
3. เปิดลิงก์ที่ขึ้นมา (ปกติคือ http://localhost:5173)

ไฟล์ `.env` เก็บ API key ของ Sphere (`VITE_SPHERE_KEY=...`) ดูตัวอย่างได้ที่ `.env.example`

### ภาพดาวเทียมรายปีและ GI Basemap ของ GISTDA (ใช้ภายในทีม)
หน้าแผนที่มีเมนู "ภาพดาวเทียมรายปี 2515–2568" (ตัวเลื่อนปี + เทียบ 2 ปีแบบเลื่อนเส้นแบ่ง), "GI Basemap" และชั้น "อาคาร 3 มิติรายหลัง (ซูมใกล้)" จาก GISTDA API Gateway
ภาพเหล่านี้เป็นลิขสิทธิ์ GISTDA ("Copyrighted by GISTDA, Fees: Yes") จึงซ่อนไว้ จนกว่า GISTDA จะอนุญาตให้เผยแพร่

เปิดในเครื่องตัวเอง:
1. ใส่ 2 บรรทัดนี้ใน `.env` (ดู `.env.example`)
   ```
   GISTDA_API_KEY=<key ของทีม>
   VITE_GISTDA_IMAGERY=1
   ```
2. ปิดแล้วเปิด `npm run dev` ใหม่ (Vite อ่าน `.env` ตอนเริ่มเท่านั้น)
3. หน้าแผนที่ > แผนที่พื้นหลัง > เลือก "ภาพดาวเทียมรายปี" หรือ "GI Basemap" · หรือ ชั้นข้อมูล > "อาคาร 3 มิติรายหลัง" (แผนที่บินไปเมืองเก่าและเอียงให้เอง)

วิธีทำงาน: เบราว์เซอร์ขอภาพจาก `/gistda/...` ของเว็บเราเอง แล้วตัวกลางเติม key ให้ (`netlify/gistda-proxy.mjs`)
ตอน `npm run dev` ตัวกลางคือ `netlify/gistda-dev-server.mjs` ตอนขึ้น Netlify คือ `netlify/functions/gistda.mjs` key จึงไม่เคยไปถึงเบราว์เซอร์
- ตัวกลางยอมให้ขอได้เฉพาะ 2 บริการนี้ และเฉพาะในกรอบภูเก็ต ส่วนผลที่ไม่ใช่ภาพ (เช่น ข้อความ error ที่อาจมี key) จะไม่ถูกส่งต่อ
- **เครดิต:** ภาพแต่ละช่อง (256 × 256 px) ที่เปิดครั้งแรกใช้ 1 คำขอ ภาพที่เคยเปิดแล้วเก็บไว้ใน `node_modules/.cache/gistda-tiles` จึงไม่เสียซ้ำ Terminal บอกจำนวนคำขอที่ส่งไป GISTDA ทุก 50 ภาพ
- อาคาร 3 มิติรายหลัง (GISTDA) เป็นแผ่นเวกเตอร์ที่ตัวกลางสร้างจาก API: ซูม 16 แผ่นละประมาณ 600 × 600 ม. มีทุกหลัง (1 คำขอ แผ่นหนาแน่นใช้ 2–5 คำขอ) ซูม 15 แผ่นละ 1.2 กม. เฉพาะหลังใหญ่หรือสูง (ใช้คำขอมากกว่า) เฉพาะแผ่นที่เห็น แผ่นที่เคยโหลดแล้วไม่ขอซ้ำ
- ชั้น **ถนนและซอยทุกประเภท** (OSM, เปิดไว้ตั้งต้น ขึ้นเมื่อซูมระดับ 14 ขึ้นไป) แสดงซอยและถนนในหมู่บ้านที่แผนที่ Sphere บางแผ่นไม่มี
- แผ่นแผนที่ถนน Sphere ที่ส่งมาว่างตอนซูมใกล้ เว็บจะใช้ส่วนของแผ่นระดับบนขยายแทน (`src/sphereFix.ts`)
- ชั้นเดียวกันเลือกเป็น **Overture** ได้ (ไฟล์ในเว็บ ไม่ต้องใช้ key คนทั่วไปเห็นด้วย) และติ๊ก "ขอบอาคาร … ซ้อน" เพื่อเทียบตำแหน่งสองแหล่ง
- ตัวเลื่อนปีรอให้หยุดเลื่อนก่อน (ประมาณครึ่งวินาที) แล้วจึงโหลดภาพปีนั้น ไม่โหลดทุกปีที่เลื่อนผ่าน และไม่ขอภาพละเอียดเกินกว่าภาพจริง (ภาพรายปีถึงซูม 15 ภาพ 2 ม. ถึงซูม 17)

## วิธีเอาขึ้นเว็บ (ฟรี)
เว็บที่ build แล้ว (`dist/`) มีขนาดประมาณ 6.5 MB 19 ไฟล์ จึงไม่ติดขีดจำกัดของ Netlify หรือ Vercel

**แบบที่แนะนำ: เชื่อม GitHub** (merge PR แล้วเว็บอัปเดตเอง)
1. สมัคร Netlify (หรือ Vercel) ด้วยบัญชี GitHub แล้วเลือก Import จาก repo `Zennsei/Phuket-Potential`
2. Netlify อ่านค่าจาก `netlify.toml` เอง (build `npm run build`, โฟลเดอร์ `dist`, Node 22) ส่วน Vercel ตรวจเจอว่าเป็น Vite เอง
3. ใส่ Environment Variable **`VITE_SPHERE_KEY`** = key ของ Sphere (ไม่ต้องใส่ `GISTDA_API_KEY` เพราะใช้แค่ในสคริปต์บนเครื่อง)
4. กด Deploy แล้วจะได้โดเมน เช่น `ชื่อ.netlify.app`
5. ไปตั้งค่า key ใน Sphere ให้ใช้ได้เฉพาะโดเมนนั้น (และ `localhost` ถ้ายังทดสอบในเครื่อง)
6. **หลัง GISTDA อนุญาตให้แสดงภาพบนเว็บสาธารณะเท่านั้น:** ใส่ `GISTDA_API_KEY` และ `VITE_GISTDA_IMAGERY=1` ใน Environment variables ของ Netlify แล้ว Deploy ใหม่ Netlify จะเก็บภาพที่ผ่าน Function ไว้ใน CDN 30 วัน คนที่เปิดดูที่เดิมจึงไม่ใช้เครดิตซ้ำ

**แบบลากวาง (Netlify Drop):** รัน `npm run build` ในเครื่องก่อน แล้วลาก **เฉพาะโฟลเดอร์ `dist`** ไปวาง ห้ามลากทั้งโปรเจกต์ (มี `node_modules` หลายร้อย MB และ `.env`) แบบนี้ key จาก `.env` ในเครื่องจะติดไปกับไฟล์ที่ build และต้องลากใหม่ทุกครั้งที่แก้ · แบบนี้ไม่มี Netlify Function ภาพ GISTDA จึงใช้ไม่ได้ และต้องลบ `VITE_GISTDA_IMAGERY=1` ออกจาก `.env` ก่อน build

## อัปเดตข้อมูล
สคริปต์อยู่ใน `data-prep/` (Python: geopandas, pyogrio, osmium)
- `osm_extract.py` ดึงถนนและสถานที่ของภูเก็ตจากไฟล์ OpenStreetMap (`thailand-latest.osm.pbf` จาก Geofabrik)
- `data_prep.py` รวมทุกข้อมูลเป็นค่ารายตำบล แล้วสร้างไฟล์ใน `public/data/`
- `bldg_grid.py` สร้างตาราง 500 ม. ของความหนาแน่นอาคาร
- `landuse_prep.py` สรุปการใช้ที่ดินปี 2563 รายตำบล และสร้างชั้นการใช้ที่ดิน
