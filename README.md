# ศักยภาพพื้นที่ภูเก็ต (Phuket Potential Map)

เว็บวิเคราะห์ศักยภาพพื้นที่รายตำบลของจังหวัดภูเก็ต สำหรับโครงการ THEOS-2 / GISTDA
ด้านการจัดการเมืองและเส้นทางระเบียงเศรษฐกิจ

เขียนด้วย **React + TypeScript + Vite** แผนที่ใช้ **MapLibre** กับแผนที่พื้นหลังจาก **GISTDA Sphere**
ไม่ต้องใช้ database ข้อมูลทั้งหมดเป็นไฟล์ใน `public/data/`

## หน้าในเว็บ
| หน้า | ทำอะไร |
|---|---|
| หน้าแรก | อธิบายโครงการ ตัวเลขสรุป และ 5 อันดับแรก |
| แผนที่วิเคราะห์ | แผนที่ 17 ตำบล ปรับหลักเกณฑ์ (น้ำหนักปัจจัย) ได้ เปิด/ปิดชั้นข้อมูล คลิกตำบลเพื่อดูรายละเอียด |
| จัดอันดับ | ตารางเรียงได้ ค้นหาได้ ดาวน์โหลด CSV/JSON |
| ภารกิจ | สื่อการเรียนรู้ 6 ขั้น: บทบาท → หลักฐาน → หลักเกณฑ์ → ตัดสินใจ → Stress Test → สรุป |
| วิธีคิดและแหล่งข้อมูล | สูตร แหล่งข้อมูล วันที่ และข้อจำกัด |

## วิธีรันในเครื่องตัวเอง
1. ติดตั้ง Node.js เวอร์ชัน 22 ขึ้นไป จาก https://nodejs.org
2. เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์
   ```
   npm ci
   npm run dev
   ```
3. เปิดลิงก์ที่ขึ้นมา (ปกติคือ http://localhost:5173)

ไฟล์ `.env` เก็บ API key ของ Sphere (`VITE_SPHERE_KEY=...`) ดูตัวอย่างได้ที่ `.env.example`

## วิธีเอาขึ้นเว็บ (ฟรี)
**Vercel หรือ Netlify** ทำได้แบบเดียวกัน:
1. เอาโฟลเดอร์นี้ขึ้น GitHub (ไม่ต้องเอา `node_modules` และ `.env` ขึ้น)
2. สมัคร Vercel ด้วยบัญชี GitHub แล้วกด Import โปรเจกต์
3. Build command: `npm run build` · Output directory: `dist`
4. ใน Environment Variables ใส่ `VITE_SPHERE_KEY` = key ของทีม
5. เมื่อได้โดเมนแล้ว ไปตั้งค่า key ใน Sphere ให้ใช้ได้เฉพาะโดเมนนั้น

## อัปเดตข้อมูล
สคริปต์อยู่ใน `data-prep/` (Python: geopandas, pyogrio, osmium)
- `osm_extract.py` ดึงถนนและสถานที่ของภูเก็ตจากไฟล์ OpenStreetMap (`thailand-latest.osm.pbf` จาก Geofabrik)
- `data_prep.py` รวมทุกข้อมูลเป็นค่ารายตำบล แล้วสร้างไฟล์ใน `public/data/`
- `bldg_grid.py` สร้างตาราง 500 ม. ของความหนาแน่นอาคาร
